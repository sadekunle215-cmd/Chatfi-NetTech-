API

The API, at a glance.

Simple requests in, clear events out.

// create a payment
POST /api/payments
{ "amount": 25, "token": "USDC" }
// check its status
GET /api/payments/{id}
{ "status": "completed" }
// receive the webhook
POST your-server.com/hook
{ "event": "payment.completed",
  "amount": 25 }

Example shapes only. Full documentation arrives with open developer access.
